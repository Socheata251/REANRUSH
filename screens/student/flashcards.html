How does magnetic flux (Φ) through a planar coil change if the coil is rotated by 90° perpendicular to a uniform magnetic field (B)?

តើម៉ាញេទិចហ្វ្លុច (Φ) ឆ្លងកាត់បូប៊ីនរាបស្មើប្រែប្រួលយ៉ាងដូចម្តេច ប្រសិនបើបូប៊ីនត្រូវបានបង្វិល 90° កាត់កែងទៅនឹងដែនម៉ាញេទិចស្មើ (B)?

Physics Formulation
Φ = B ⋅ A ⋅ cos(θ)

Where θ is the angle between field vector B and area normal vector n̂.

help Think first before revealing the proof!
ANSWER KEY • គន្លឹះចម្លើយ Verified BACII Proof
verified

Φ drops to 0 Weber (Wb) • ហ្វ្លុចធ្លាក់ចុះដល់សូន្យ

Because the normal vector becomes perpendicular (90°) to the magnetic field, cos(90°) = 0. Therefore, no field lines pierce through the plane of the loop.

Key Exam Steps / ដំណោះស្រាយតាមលំដាប់លំដោយ:

  • Initial state: θ = 0° → Φmax = B ⋅ A ⋅ cos(0°) = B ⋅ A
  • Final rotated state: θ = 90° → cos(90°) = 0 → Φ = 0
  • Khmer note: កាលណាផ្ទៃបូប៊ីនស្របនឹងខ្សែដែន ⇒ វ៉ិចទ័រណរម៉ាល់កាត់កែងនឹងដែន ⇒ Φ = 0
